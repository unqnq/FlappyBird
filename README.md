# 🐤 Flappy Bird Clone (Unity)

This is an enhanced **Flappy Bird** clone made with Unity, featuring core gameplay, audio control via mixers, full localization support, and persistent coin tracking. A shop system for character and background customization is planned for future updates.

---

## 🎮 Gameplay

- Tap to keep the bird in the air.
- Avoid pipes to stay alive.
- Each pipe passed = **1 coin**.
- The longer you survive, the more coins you collect!

---

## 🧰 Features

### 🔊 Audio System

- 🎵 Background music and UI sound effects.
- 🎚️ Separate volume sliders for music and effects.
- 🔄 Real-time adjustments in the settings menu.
- 🎛️ Managed using Unity's **Audio Mixer**.
- 🔁 Persistent `AudioManager` using `DontDestroyOnLoad`.

### 🌍 Localization

- Supports **English** 🇬🇧 and **Ukrainian** 🇺🇦.
- Language can be changed via dropdown in the settings.
- UI texts and descriptions update automatically.

### 💰 Coin System

- Earn **1 coin** for every pipe you pass.
- Coins are saved **between play sessions**.
- Stored using PlayerPrefs.

---

## 🛍️ Planned Features

- 🛒 In-game shop to spend coins:
  - Unlockable bird sprites.
  - Custom background themes.
- 🎨 Personalize your game experience with collected coins.
